# 0.1.3 桌面 GUI

使用说明见 [Windows 发布版说明](WINDOWS_RELEASE.md)。可在图形面板中添加多个 Mod 源文件夹。

深色桌面控制面板提供侧栏导航、状态卡片、单按钮服务启停、路径与端口设置、
CWT 语料检查及更新、HTTP / stdio / Codex 配置复制、实时日志和关于软件页面。
服务启动时按钮内显示旋转状态，运行后切换为红色停止按钮。控制台按钮可复制完整的 HTTP 接入配置。
语料检查与更新共用一个按钮，下载进度按完成文件数显示，更新时退出可选择继续等待或中断。
源文件夹横向排列，悬停可删除；增删后自动保存，并全部参与后端解析。数据页可滚动，窗口缩小时仍能找到检查更新按钮。

主程序使用 Windows GUI 子系统，双击不会打开控制台。后台任务使用独立进程，
通过队列将日志及完成事件交给 UI 线程，网络请求和索引构建不会阻塞窗口。
服务运行时锁定相关设置，更新期间禁止启动服务；关闭窗口仅停止自身创建的进程。
语料安装使用验证与回滚流程；主动选择「仍然退出」会中断后台更新进程。

stdio 保留控制台子系统的独立服务 EXE，确保 MCP 的 stdin / stdout 管道可用。
两者共享 _internal 中的 Python、GUI 依赖与语料，避免重复分发运行库。
源码核心服务仍不依赖 GUI 库；GUI 可通过 requirements-gui.txt 单独安装。

回归范围包括设置保存/异常恢复、中文路径、配置参数、真实后台服务的
启动/握手/停止及端口释放、端口占用、更新检查失败与桌面状态转换。
完整结果见 TEST_REPORT.txt / TEST_REPORT.json。
