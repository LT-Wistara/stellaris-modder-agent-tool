# 文档索引

使用方式见 [项目 README](../README.md)、[Windows 发布版说明](WINDOWS_RELEASE.md)、[数据源说明](DYNAMIC_DATA.md) 和 [架构说明](ARCHITECTURE.md)。多个 Mod 目录可在 GUI 中添加，或重复使用 `--mod-root` 指定；环境变量 `STELLARIS_MOD_ROOT` 可指定一个目录。
