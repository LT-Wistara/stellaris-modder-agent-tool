Stellaris Modder Agent 0.1.3

Windows 发布版：双击 StellarisModderAgent.exe 打开图形面板。
面板中可启动 / 停止服务、设置游戏与 Mod 路径、更新 CWT 语料、复制客户端配置。
保留 StellarisModderAgent-server.exe 与 _internal 文件夹，无需安装 Python。

源码版：先运行 python -m pip install -r requirements-gui.txt，再运行 python gui.py。
原有 start.cmd / start.py 仍提供命令行服务入口。

详见 README.md 与 docs/WINDOWS_RELEASE.md。
